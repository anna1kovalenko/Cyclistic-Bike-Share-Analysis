# 🚲 Cyclistic Bike-Share Analysis (Python)

## 📄 Project Overview
This is a Capstone Project for the **Google Data Analytics Professional Certificate**.
**Goal:** Analyze how casual riders and annual members use Cyclistic bikes differently to design a new marketing strategy.

## 🛠 Tools Used
*   **Language:** Python
*   **Libraries:** Pandas, Matplotlib, Seaborn, NumPy
*   **Environment:** Jupyter Notebook

## 📊 Key Insights
1.  **Ride Duration:** Casual riders ride **2x longer** than annual members on average.
2.  **Weekly Patterns:**
    *   **Members** use bikes mainly on weekdays (Commuting).
    *   **Casuals** dominate on weekends (Leisure).
3.  **Bike Preference:** Both groups prefer electric bikes, but casuals are highly active on weekends.

## 📂 How to run this code
1.  Download the `Cyclistic_Analysis.ipynb` file from this repository.
2.  Download the dataset from the official source: [https://divvy-tripdata.s3.amazonaws.com/index.html].
3.  **Select the data:** I used 12 files covering the period from **november 2024** to **oktober 2025**.
    *   *Example files: `202411-divvy-tripdata.zip` to `202510-divvy-tripdata.zip`.*
4.  Unzip the CSV files and place them **in the same folder** as the notebook file.
5.  Run the Jupyter Notebook.
